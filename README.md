# NuBest Tall Gummies — Product Page

A lightweight, static product landing page for **NuBest Tall Gummies**, a sugar-free, berry-flavored gummy multivitamin formulated for kids ages 2+ and teens.

Built with plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies.

## Preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

```
.
├── index.html   # Page markup and content
├── style.css    # Visual design (Fraunces + Inter type system, forest/berry palette)
├── script.js    # Single interaction: expand/collapse the full nutrient list
└── README.md    # This file
```

## Content sections

- **Hero** — product positioning, price, and a floating nutrient card
- **Taste** — an honest description of flavor and texture
- **What it's formulated to do** — bone, brain/eye, and immune support, with hedged language
- **The journey** — a 3-stage timeline (30 days / 2–4 months / 6+ months)
- **Facts & safety** — dosing directions and allergen-free claims
- **Footer** — full FDA/FTC disclaimer block and link to the official product page

## Compliance notes

- All benefit language uses hedged phrasing ("may help support," "designed to help support") rather than absolute claims, per standing content-integrity rules.
- The full disclaimer block (FDA statement, individual-results variance, physician consultation) is included in the footer and must not be removed or shortened when this page is reused or adapted.
- Product facts, pricing, and ingredient list are sourced from the official NuBest product page and should be re-verified there before publishing, as pricing and formulation can change.
